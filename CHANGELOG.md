# Changelog

## Unreleased

## [0.4.0](https://github.com/sparr/messagefromaliens-mod-Calculator/releases/tag/v0.4.0) - 2026-11-23

- Values stay exact, fractions are shown as the game shows them, and results that lose a remainder are marked approximate.
- Back undoes the last key press.
- Features unlock by a count of chapter quizzes won, like the game's own gates, with unlock messages and gated settings through Mod Settings.
- The calculator closes on a left panel click, a new history entry, or loading a save.
- Fixed keys typed into text fields reaching the calculator.

## [0.3.0](https://github.com/sparr/messagefromaliens-mod-Calculator/releases/tag/v0.3.0) - 2026-11-15

- Added an E key for scientific form.
- The point key cycles through repeating fraction forms, replacing the repeat key.

## [0.1.0](https://github.com/sparr/messagefromaliens-mod-Calculator/releases/tag/v0.1.0) - 2026-11-15

- Initial release: a base 7 calculator in the left panel that unlocks with quiz progress.
